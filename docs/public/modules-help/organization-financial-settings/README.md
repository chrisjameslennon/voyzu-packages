# Organization Financial Settings

Organization Financial Settings contains the shared financial model and default records used across Voyzu.

## Concepts

* [Organizations and Companies](../../concepts/organizations-and-companies.md) explains the organization and company model.
* [Financial Settings and Tethering](/broken/pages/8yyiyzggr2y0AScYWDBt) explains which settings flow through to companies.
* [Financial Document Processing](../../concepts/financial-document-processing.md) explains how configuration drives posting.
* [Control Accounts](../../concepts/control-accounts.md) explains ledger-backed accounts.
* [Inventory](../../concepts/inventory.md) and [Tax](../../concepts/tax.md) cover those specialist areas.

## Using this area

Use **Organization** and **Companies** to maintain the group and its separate financial entities. **Localization** provides countries, currencies, and country tax configuration. **Organization Standard Settings** defines general ledger accounts, control accounts, integration settings, dimensions, document behavior, and posting profiles. **New Company Defaults** supplies inventory records copied when a company is created.

Open the help from the screen you are using. Each page explains that screen's fields, usage restrictions, available actions, and related concepts. Read-only catalogues and mappings intentionally do not offer create, edit, status, or delete instructions.

## Before making changes

Determine whether the record is an organization standard, a company-specific record, or a copied default. Check whether it is in use or has postings. Structural changes can affect later posting and reporting, while historical financial entries remain immutable.
