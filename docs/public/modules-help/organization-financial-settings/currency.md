# Currencies

The Currencies screens show the currency reference data available to companies and financial processing.

## Concepts

* [Countries and Currencies](/broken/pages/ICKzNx93K3ivfw7Y7LJA) explains company country and base-currency selection.
* [Organizations and Companies](../../concepts/organizations-and-companies.md) explains why every company maintains its own financial records and currency context.

## Viewing currencies

The list shows currency code, name, symbol, and status. Search matches those values. Use **Filter** to select statuses, click a row to open its detail, and use **Refresh** to reload the list.

Export can include the selected currency, the current searched or filtered view, or the full dataset.

Currencies are read-only reference data in the application. They are not created, edited, activated, deactivated, or deleted from these screens.

## Reading a currency

The detail screen shows the ISO currency code, display name, symbol, status, posting state, and audit information.

### In use

The **HAS POSTINGS** badge means the currency is referenced by existing financial records. The badge is informational because currency details are read-only.

The audit panel links to the organization audit log for the selected currency.
